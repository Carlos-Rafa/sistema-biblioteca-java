 📚 Sistema Bancário 

> Um sistema desenvolvido em Java aplicando os pilares da Programação Orientada a Objetos (POO) para gerenciamento e controle de regras de negócio.


🚀 Sobre o Projeto

Este projeto tem como objetivo principal colocar em prática conceitos fundamentais de desenvolvimento de software, como encapsulamento, relacionamentos entre classes, tratamento de fluxos de navegação (menus via console) e organização arquitetural em camadas.



🛠️ Tecnologias Utilizadas

- Linguagem:** Java
- Paradigma:** Orientação a Objetos (POO)
- Ambiente:** Console / Terminal



⚙️ Funcionalidades Principais

- Gerenciamento de Usuários/Clientes:** Cadastro e controle de acesso inicial.
- Operações do Sistema:** Fluxos lógicos estruturados com validações de segurança (como verificação de dados e estados).
- Menus Interativos:** Navegação organizada por etapas (Menu Inicial e Menu Logado/Operacional).



🏛️ Arquitetura e Modelagem

O projeto foi estruturado separando responsabilidades para manter o código limpo e fácil de manter:

- Classes de Domínio/Entidades:** Representam os moldes dos dados principais.
- Classes de Controle/Serviço:** Gerenciam as regras de negócio, validações e iterações.
- Fluxo de Execução:** Controle de menus e interações com o usuário via terminal.

💡 Aprendizados e Evolução

Este projeto faz parte de uma jornada de aprendizado prático em desenvolvimento de software, focando em:

* Escrever códigos limpos e coesos.
* Evitar complexidades desnecessárias (aplicando o princípio *KISS - Keep It Simple, Stupid*).
* Entender a comunicação entre diferentes classes e objetos.
